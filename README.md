# SQL Queries

A personal collection of SQL queries written while practising and learning relational database concepts.

## Contents

- `sql queries.rtf` - the queries, saved as a rich-text document.

## Topics covered

Practice with core SQL such as creating tables, inserting and selecting data, filtering, sorting, grouping and joins.

## How to use

1. Open `sql queries.rtf` in any text editor or word processor.
2. Copy the queries into your SQL client (MySQL, PostgreSQL, SQLite, etc.) and run them.
